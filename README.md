# HeroJourney
A Zelda-style top-down adventure game built from scratch in C using raylib.

This is my first large-scale coding project. It's still a work in progress, 
but the current demo reflects my ability to structure a complex codebase, 
compartmentalize interdependent systems (combat, physics, AI, rendering, and more), 
and debug low-level issues as the project scales.

This entire codebase has been written using the w64devkit and vim. AI was only 
utilized to write logic understanding HID controller input, everything else was completely coded, debugged, and designed by myself.
